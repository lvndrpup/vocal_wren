# Start here

Vocal Wren is a free Android vocal trainer that runs entirely on your phone: it measures
pitch, resonance and vocal weight, and audio never leaves the device. This site is for
people who work on it.

- **New to voice science?** [Learn](learn/README.md) explains pitch, formants and weight
  from first principles.
- **Want the rules?** The [constitution](constitution.md) lists the principles every change
  must keep, and the [roadmap](roadmap.md) says what is being built when.
- **Looking for a decision?** Each one is an ADR under Decisions in the sidebar.
- **Looking up a term or an ID?** See the [glossary](reference/glossary.md).

The source and the issue tracker are on
[GitHub](https://github.com/lvndrpup/vocal_wren).
