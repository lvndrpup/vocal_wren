# API (:core)

The [API reference for `:core`](api/index.html) is generated from the KDoc comments in
`android/core` by Dokka on every build of this site. `:core` holds all of Vocal Wren's
DSP, analysis, confidence, safety and coaching logic ([ADR-0006](adr/0006-pure-kotlin-core-module.md)).
`:app` is UI and Android glue and has no API reference.
